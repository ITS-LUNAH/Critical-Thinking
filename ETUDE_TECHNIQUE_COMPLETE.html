Vue d'ensemble du projet

Qu'est-ce que Critical Thinking ?

Critical Thinking est une plateforme pédagogique interactive composée de 4 jeux différents, conçus pour développer les compétences de pensée critique chez les utilisateurs. Chaque jeu propose une approche unique pour améliorer le raisonnement, l'analyse et la prise de décision.

Jeu 1: Challenge de Pensée Critique

Type: Jeu d'ordonnancement | Mécanique: Classer les étapes dans le bon ordre

Description du Jeu

Concept

L'utilisateur reçoit une situation (exemple: "Organiser un événement") avec plusieurs étapes présentées dans un ordre aléatoire. Son défi est de les reclasser dans le bon ordre logique.

Logique Métier

1. Charger une Situation Aléatoire

Fonction: getRandomSituation() | Fichier: app/models/Game.php
public function getRandomSituation() { // Récupère une situation aléatoire de la base de données // MySQL utilise RAND() pour randomiser l'ordre $stmt = $this->db->query( "SELECT * FROM situations ORDER BY RAND() LIMIT 1" ); return $stmt->fetch(); }
Explication:
  • Utilise RAND() de MySQL pour obtenir une situation aléatoire
  • LIMIT 1 récupère un seul résultat
  • Le résultat est un tableau associatif contenant id, titre, description

2. Récupérer les Étapes Mélangées

public function getStepsForSituation($situation_id) { // Prépare la requête pour éviter les injections SQL $stmt = $this->db->prepare( "SELECT * FROM steps WHERE situation_id = ?" ); // Exécute la requête avec l'ID de la situation $stmt->execute([$situation_id]); // Récupère tous les résultats $steps = $stmt->fetchAll(); // Mélange les étapes pour le jeu (ordre aléatoire) shuffle($steps); return $steps; }
Points clés:
  • Utilise prepare() et execute() pour sécuriser la requête
  • shuffle() mélange le tableau des étapes
  • Chaque situation possède plusieurs étapes avec un step_order

3. Vérifier l'Ordre Soumis

public function checkOrder($situation_id, $user_order) { // Récupère les bonnes étapes dans l'ordre correct $stmt = $this->db->prepare( "SELECT id, step_order FROM steps WHERE situation_id = ? ORDER BY step_order ASC" ); $stmt->execute([$situation_id]); $correct_steps = $stmt->fetchAll(); $is_correct = true; // Vérifie si chaque étape soumise correspond à la position correcte foreach ($correct_steps as $index => $correct_step) { // Compare l'ID soumis avec l'ID correct if (!isset($user_order[$index]) || $user_order[$index] != $correct_step['id']) { $is_correct = false; break; } } return $is_correct; }
Algorithme de vérification:
  • Récupère les étapes correctes triées par step_order
  • Compare chaque position de la réponse avec la position correcte
  • Retourne false dès qu'une erreur est détectée
  • Nécessite une correspondance exacte et dans le bon ordre

Appel du Controller

public function index() { // Charge le modèle Game $gameModel = $this->model('Game'); // Récupère une situation aléatoire $situation = $gameModel->getRandomSituation(); // Récupère les étapes mélangées pour cette situation $steps = $gameModel->getStepsForSituation($situation['id']); // Passe les données à la vue $this->view('game/index', [ 'situation' => $situation, 'steps' => $steps ]); }

Jeu 2: Quiz de Pensée Critique

Type: Choix multiple | Mécanique: 4 réponses par question

Description du Jeu

Concept

Un quiz classique où l'utilisateur doit choisir la bonne réponse parmi 4 options pour chaque question. Les réponses sont validées en temps réel et le score est accumulé.

Données du Quiz

{ "quiz": [ { "id": 1, "question": "Lequel de ces éléments est un biais cognitif ?", "options": [ "Biais de confirmation", "Biais de calcul", "Biais de vision", "Biais de mémoire" ], "answer": 0, "explanation": "Le biais de confirmation est..." } ] }
Structure des données:
  • id: Identifiant unique de la question
  • question: Le texte de la question
  • options: Tableau de 4 réponses possibles
  • answer: Index (0-3) de la bonne réponse
  • explanation: Explication de la réponse correcte

Logique du Controller

1. Initialisation du Quiz

public function quiz($index = 0) { // Démarre la session PHP session_start(); // Charge toutes les questions $questionModel = $this->model('Question'); $questions = $questionModel->getAllQuiz(); // Initialise le score de session (première fois) if (!isset($_SESSION['quiz_score'])) { $_SESSION['quiz_score'] = 0; $_SESSION['quiz_total'] = 0; } // Vérifie si le quiz est fini if ($index >= count($questions)) { // Affiche le résumé final $this->view('game/quiz_finished', [ 'score' => $_SESSION['quiz_score'], 'total' => $_SESSION['quiz_total'] ]); // Réinitialise la session unset($_SESSION['quiz_score']); unset($_SESSION['quiz_total']); return; } // Affiche la question actuelle $this->view('game/quiz', [ 'question' => $questions[$index], 'currentIndex' => $index, 'totalQuestions' => count($questions), 'score' => $_SESSION['quiz_score'] ]); }

2. Vérification de la Réponse

public function quizcheck() { // Vérifie que c'est une requête POST if ($_SERVER['REQUEST_METHOD'] == 'POST') { session_start(); // Récupère les données de la réponse $id = $_POST['id']; $choice = $_POST['choice']; $currentIndex = $_POST['currentIndex']; // Charge la question $questionModel = $this->model('Question'); $question = $questionModel->getQuizById($id); // Vérifie si la réponse est correcte $isCorrect = ($question['answer'] == $choice); // Met à jour le score de session $_SESSION['quiz_total']++; if ($isCorrect) { $_SESSION['quiz_score']++; } // Affiche la vue avec le feedback $this->view('game/quiz', [ 'question' => $question, 'isCorrect' => $isCorrect, 'choice' => $choice, 'nextIndex' => $currentIndex + 1, 'score' => $_SESSION['quiz_score'], 'total' => $_SESSION['quiz_total'] ]); } }
Processus:
  • 1. Récupère l'index de la question actuelle
  • 2. Compare la réponse soumise avec la bonne réponse
  • 3. Incrémente le total et le score si correct
  • 4. Passe à la question suivante (nextIndex = currentIndex + 1)

Gestion de la Session

La session PHP stocke deux variables:
  • quiz_score: Nombre de bonnes réponses
  • quiz_total: Nombre total de questions répondues

Jeu 3: Fait ou Fiction

Type: Binaire (Vrai/Faux) | Mécanique: Identifier les faits vrais

Description du Jeu

Concept

L'utilisateur lit des affirmations et doit déterminer si elles sont Vraies ou Fausses. C'est un exercice de fact-checking et de pensée critique pour identifier les mythes urbains et les fausses croyances.

Exemples de Données

{ "factfiction": [ { "id": 1, "statement": "Nous n'utilisons que 10% de notre cerveau.", "is_fact": false, "explanation": "C'est un mythe. L'imagerie montre que..." }, { "id": 4, "statement": "L'ancrage cognitif consiste à se fier à la première info.", "is_fact": true, "explanation": "C'est un biais cognitif bien connu..." } ] }
Structure:
  • id: Identifiant unique
  • statement: L'affirmation à évaluer
  • is_fact: Boolean (true = vrai, false = faux)
  • explanation: Explication de la réponse

Logique du Controller

1. Initialisation

public function fact($index = 0) { session_start(); // Charge toutes les affirmations $questionModel = $this->model('Question'); $questions = $questionModel->getAllFactFiction(); // Initialise les variables de session if (!isset($_SESSION['fact_score'])) { $_SESSION['fact_score'] = 0; $_SESSION['fact_total'] = 0; } // Vérifie la fin du jeu if ($index >= count($questions)) { $this->view('game/fact_finished', [ 'score' => $_SESSION['fact_score'], 'total' => $_SESSION['fact_total'] ]); unset($_SESSION['fact_score']); unset($_SESSION['fact_total']); return; } $this->view('game/fact', [ 'question' => $questions[$index], 'currentIndex' => $index, 'totalQuestions' => count($questions), 'score' => $_SESSION['fact_score'] ]); }

2. Vérification de la Réponse

public function factcheck() { if ($_SERVER['REQUEST_METHOD'] == 'POST') { session_start(); // Récupère la réponse (string 'true' ou 'false') $id = $_POST['id']; $choice = $_POST['choice'] === 'true'; $currentIndex = $_POST['currentIndex']; // Charge la question/affirmation $questionModel = $this->model('Question'); $question = $questionModel->getFactFictionById($id); // Vérifie si la réponse est correcte // Compare le booléen de la réponse avec is_fact $isCorrect = ($question['is_fact'] == $choice); // Met à jour le score $_SESSION['fact_total']++; if ($isCorrect) { $_SESSION['fact_score']++; } $this->view('game/fact', [ 'question' => $question, 'isCorrect' => $isCorrect, 'choice' => $choice, 'nextIndex' => $currentIndex + 1, 'score' => $_SESSION['fact_score'], 'total' => $_SESSION['fact_total'] ]); } }
Points importants:
  • La réponse arrive en string ("true" ou "false") via POST
  • === 'true' convertit la string en booléen
  • Comparaison directe: is_fact == choice
  • Même structure de session que le quiz

Comparaison Quiz vs Fact/Fiction

Aspect Quiz Fact/Fiction
Type de réponse 4 choix (0-3) 2 choix (true/false)
Vérification answer == choice is_fact == choice
Complexité Plus d'options = plus difficile Plus simple mais trompeuse
Apprentissage Connaissance théorique Fact-checking pratique

Système d'Authentification

Mécanisme: Session PHP | Sécurité: Password hashing avec bcrypt

Gestion des Utilisateurs

Les utilisateurs sont stockés en base de données avec des mots de passe hashés de manière sécurisée. Chaque session utilisateur est gérée par PHP avec des identifiants de session.

1. Inscription (Signup)

public function signup() { // Vérifie que c'est une requête POST if ($_SERVER['REQUEST_METHOD'] !== 'POST') { echo json_encode([ 'success' => false, 'message' => 'Méthode non autorisée' ]); return; } // Récupère les données du formulaire $username = $_POST['username'] ?? ''; $email = $_POST['email'] ?? ''; $password = $_POST['password'] ?? ''; // Validation 1: Tous les champs sont obligatoires if (empty($username) || empty($email) || empty($password)) { echo json_encode([ 'success' => false, 'message' => 'Veuillez remplir tous les champs' ]); return; } // Validation 2: L'email n'existe pas déjà $userModel = new User($db); if ($userModel->emailExists($email)) { echo json_encode([ 'success' => false, 'message' => 'Cet email est déjà utilisé' ]); return; } // Création du compte avec password hashé if ($userModel->create($username, $email, $password)) { // Récupère l'utilisateur créé $user = $userModel->findByEmail($email); // Crée la session PHP session_start(); $_SESSION['user_id'] = $user['id']; $_SESSION['username'] = $user['username']; echo json_encode(['success' => true]); } else { echo json_encode([ 'success' => false, 'message' => 'Erreur lors de la création du compte' ]); } }

2. Connexion (Login)

public function login() { if ($_SERVER['REQUEST_METHOD'] !== 'POST') { echo json_encode([ 'success' => false, 'message' => 'Méthode non autorisée' ]); return; } $email = $_POST['email'] ?? ''; $password = $_POST['password'] ?? ''; // Validation des champs if (empty($email) || empty($password)) { echo json_encode([ 'success' => false, 'message' => 'Veuillez remplir tous les champs' ]); return; } // Cherche l'utilisateur par email $userModel = new User($db); $user = $userModel->findByEmail($email); // Vérifie le password avec password_verify (hashing sécurisé) if ($user && password_verify($password, $user['password'])) { // Identifiants valides: crée la session session_start(); $_SESSION['user_id'] = $user['id']; $_SESSION['username'] = $user['username']; echo json_encode(['success' => true]); } else { // Identifiants invalides echo json_encode([ 'success' => false, 'message' => 'Email ou mot de passe incorrect' ]); } }
Sécurité: password_verify() compare le mot de passe saisi avec le hash stocké. Le mot de passe n'est jamais stocké en clair - seul le hash est conservé en base.

3. Déconnexion (Logout)

public function logout() { session_start(); session_unset(); // Efface les variables de session session_destroy(); // Détruit la session header('Location: /Game_critical_thinking/public/'); exit; }

Architecture Base de Données

Tables Principales

1. Table: users

CREATE TABLE users ( id INT PRIMARY KEY AUTO_INCREMENT, username VARCHAR(100) NOT NULL UNIQUE, email VARCHAR(100) NOT NULL UNIQUE, password VARCHAR(255) NOT NULL, created_at TIMESTAMP DEFAULT CURRENT_TIMESTAMP );
Colonnes:
  • id: Clé primaire, auto-incrémentée
  • username: Nom unique de l'utilisateur
  • email: Email unique (adresse de connexion)
  • password: Hash du mot de passe (sha256 ou bcrypt)
  • created_at: Date/heure de création du compte

2. Table: situations (Puzzle)

CREATE TABLE situations ( id INT PRIMARY KEY AUTO_INCREMENT, title VARCHAR(200) NOT NULL, description TEXT, category VARCHAR(100), difficulty INT DEFAULT 1, created_at TIMESTAMP DEFAULT CURRENT_TIMESTAMP );
Colonnes:
  • id: Identifiant de la situation
  • title: Titre du défi (ex: "Organiser un événement")
  • description: Description longue du contexte
  • category: Type de situation (travail, personnel, etc)
  • difficulty: Niveau de difficulté (1-5)

3. Table: steps (Étapes du Puzzle)

CREATE TABLE steps ( id INT PRIMARY KEY AUTO_INCREMENT, situation_id INT NOT NULL, step_text VARCHAR(500), step_order INT NOT NULL, FOREIGN KEY (situation_id) REFERENCES situations(id) );
Relationship: Une situation possède plusieurs étapes
  • id: Identifiant unique d'une étape
  • situation_id: Référence à la situation (Foreign Key)
  • step_text: Description de l'étape à classifier
  • step_order: Position correcte (1, 2, 3, etc)

4. Table: questions (Quiz)

CREATE TABLE questions ( id INT PRIMARY KEY AUTO_INCREMENT, type ENUM('quiz', 'factfiction') NOT NULL, question_text TEXT NOT NULL, option_a VARCHAR(255), option_b VARCHAR(255), option_c VARCHAR(255), option_d VARCHAR(255), answer INT, is_fact BOOLEAN, explanation TEXT, difficulty INT DEFAULT 1 );
Colonnes:
  • type: 'quiz' (4 choix) ou 'factfiction' (vrai/faux)
  • question_text: La question ou affirmation
  • option_a/b/c/d: Les 4 options (null pour fact/fiction)
  • answer: Index de la bonne réponse (0-3)
  • is_fact: Boolean pour fact/fiction
  • explanation: Explication pédagogique

Opérations de Base Données

Requête: Obtenir une situation aléatoire

SELECT * FROM situations ORDER BY RAND() LIMIT 1; -- Résultat: Une situation au hasard

Requête: Obtenir les étapes d'une situation

SELECT id, step_text, step_order FROM steps WHERE situation_id = ? ORDER BY step_order ASC; -- Résultat: Étapes triées dans le bon ordre

Requête: Vérifier une réponse au quiz

SELECT answer, explanation FROM questions WHERE id = ? AND type = 'quiz'; -- Compare answer avec user_choice

Requête: Créer un utilisateur

INSERT INTO users (username, email, password, created_at) VALUES (?, ?, ?, NOW()); -- password = password_hash($password, PASSWORD_BCRYPT)
