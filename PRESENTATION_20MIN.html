ÉTUDE TECHNIQUE - 7 min

Architecture Base de Données

4 Tables Principales

  • users: Stocke les comptes utilisateurs (email, password_hash)
  • situations: Les scénarios du jeu Puzzle
  • steps: Les étapes à ordonner pour chaque situation
  • questions: Les questions pour Quiz et Fact/Fiction

Relations

users → (many) game_sessions
situations → (many) steps
questions → (many) quiz_answers
